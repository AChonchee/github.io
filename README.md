# เกมท่องคำ ธงชาติ 🌏

เกมทายธงสำหรับห้องเรียน ต่อยอดจาก **เกมท่องคำหมูหมากาไก่** โดยเปลี่ยนจากรูปสัตว์เป็น
**ธงชาติ 7 ประเทศ** — สหรัฐอเมริกา, ฝรั่งเศส, อังกฤษ, จีน, ออสเตรเลีย, ญี่ปุ่น, ไทย

ชื่อประเทศ **ซ่อนไว้** ให้เด็กทายจากธงก่อน แล้วครูค่อยกดปุ่ม **“เฉลย”** ใต้ธงแต่ละใบ

## วิธีใช้

ดับเบิลคลิก `index.html` — จบ ไม่ต้องติดตั้งอะไร ไม่ต้องต่ออินเทอร์เน็ต
(ต้องเก็บไฟล์ `sound01.mp3` ไว้ข้าง `index.html` เสมอ เพราะเป็นเพลงประกอบ)

| ปุ่ม / ปุ่มลัด | ทำอะไร |
|---|---|
| ▶️ เล่น / `Space` | เริ่มเกม — **เตรียมตัว 3 วิ (ครั้งเดียวตอนเริ่มรอบ) → “หมู หมา กา ไก่”** ก่อนสปอตไลต์เริ่มวิ่ง (กดซ้ำเพื่อหยุดได้ตลอด รวมถึงตอนอยู่ในท่อนเปิด) |
| **เฉลย ❓** (ใต้ธงแต่ละใบ) | กดเพื่อแสดงชื่อประเทศใบนั้น กดซ้ำเพื่อซ่อนกลับ |
| 👁 เฉลยทั้งหมด | เฉลยครบทุกใบในครั้งเดียว กดซ้ำกลายเป็น 🙈 ซ่อนทั้งหมด |
| **5 ชุด / 10 ชุด** | เลือกความยาวของรอบ — เกมจะจำค่าที่เลือกไว้ให้ครั้งต่อไป |
| ← → | ข้ามชุด = สุ่มธงชุดใหม่ (หยุดเกมก่อนอัตโนมัติ) |
| 🔊 / 🔈 | เสียงเฉลยชื่อประเทศตอนสปอตไลต์วิ่ง — **ค่าตั้งต้นปิดไว้** ไม่งั้นจะเฉลยให้เองหมด |
| 🎵 / 🔇 | เปิด-ปิดเพลงประกอบ |
| 📁 เลือกเพลง + แถบเสียง | เปลี่ยนเพลงเฉพาะคาบนั้น และปรับระดับเสียง |
| ⛶ หรือ `F` | เต็มจอ |
| แถบความเร็ว | 5 ระดับ: 1500 / 1100 / 800 / 600 / 400 มิลลิวินาทีต่อธง — **ค่าตั้งต้นคือระดับ 5 (400 มิลลิวินาที)** |
| ปุ่มเลขชุด | กระโดดไปชุดที่ต้องการ (แต่ละชุดสุ่มธงใหม่) |

### การเล่น 1 รอบ

```
กด "เล่น"
  → ⏳ เตรียมตัว… 3 วินาที (จุด 3 ดวงติดทีละดวง)   ← ขึ้นครั้งเดียวตอนเริ่มรอบ
  → 🐷 หมู  🐶 หมา  🐦 กา  🐔 ไก่                    ← ท่อนเปิด ไม่มีเสียงพูด
  → ชุด 1: สปอตไลต์วิ่งไล่ธงทีละใบ 8 ใบ  ให้เด็กทายชื่อประเทศตามจังหวะ
  → สุ่มธงชุดใหม่ + ขึ้น หมู หมา กา ไก่ อีกครั้ง 2.75 วิ (ไม่มีเตรียมตัว ไม่มีนับถอยหลัง)
  → ชุด 2 ... จนถึงชุดสุดท้าย (5 หรือ 10 ตามที่เลือก) แล้วหยุดเอง
```

ช่วง “เตรียมตัว…” ขึ้น**ครั้งเดียวตอนเริ่มรอบ** (3 วินาที) หลังจากนั้นทุกชุดขึ้นแค่ท่อน
หมู หมา กา ไก่ โดย**ชุดแรก 3.00 วินาที ส่วนชุดที่ 2 ขึ้นไปเท่ากันหมดที่ 2.75 วินาที**
(ชุดแรกช้ากว่าเล็กน้อยให้เด็กจับจังหวะก่อน จากนั้นคงที่ตลอดรอบ)

รอบ 10 ชุดที่ความเร็วระดับ 5 (ค่าตั้งต้น) ใช้เวลาประมาณ 1 นาที ถ้าลดเป็นระดับ 3 จะราว 1 นาที 35 วินาที
(รอบ 5 ชุดที่ระดับ 5 ราวครึ่งนาที)

ปรับจังหวะท่อนเปิดได้ที่ค่าคงที่ 2 ตัวในสคริปต์: `CHANT_FIRST_MS` (ชุดแรก),
`CHANT_NEXT_MS` (ชุดที่ 2 ขึ้นไป)

สลับจำนวนชุดระหว่างเล่นได้ เกมจะหยุดแล้วเริ่มที่ชุด 1 ใหม่

ชื่อที่เฉลยไปแล้วจะ **ซ่อนกลับอัตโนมัติ** ทุกครั้งที่กดเล่นหรือขึ้นชุดใหม่

### กติกาการสุ่มในแต่ละชุด

การ์ดวางเป็น **แถวบน 4 ใบ + แถวล่าง 4 ใบ** (รวม 8 ใบ) สุ่มแยกกันทีละแถวจากบ่อ 7 ประเทศ

- ภายในแถวเดียวกัน **ไม่ซ้ำกัน**
- ข้ามแถว **ซ้ำกันได้** เช่น “ไทย” โผล่ทั้งแถวบนและแถวล่าง
- เพราะมี 8 ช่องแต่มีแค่ 7 ประเทศ **ทุกชุดจึงมีประเทศซ้ำข้ามแถวอย่างน้อย 1 ประเทศเสมอ**
- ทุกชุดสุ่มใหม่หมด ธงจึงไม่เหมือนเดิมสักชุด

ถ้าอยากเปลี่ยนกติกา แก้ `const ROW_SIZES = [4,4]` ในสคริปต์บรรทัดเดียว
เช่น `[4,3]` = 7 ใบ (บน 4 ล่าง 3), `[3,3]` = 6 ใบ

## เพลงประกอบ

เกมใช้ไฟล์เพลงจริงเป็นเสียงพื้นหลัง วนลูปตลอดรอบการเล่น

**โครงไฟล์ที่ต้องมี** — `sound01.mp3` ต้องอยู่ข้าง `index.html` เสมอ:

```
GAME\
  index.html
  sound01.mp3        ← เพลงพื้นหลัง
```

- กด ▶️ → เพลงเริ่มจากต้นพร้อมช่วง “เตรียมตัว…” แล้ววนต่อเนื่องข้ามชุดไม่สะดุด
- กดหยุด → เพลงหยุดและกรอกลับต้นเพลง
- แถบเสียงข้างปุ่ม “เลือกเพลง” ปรับระดับได้ ค่าตั้งต้น 60% (ตั้งไว้ไม่ให้กลบเสียงครู)

**เปลี่ยนเพลงถาวร** — เอาไฟล์ใหม่ไปวางแทนที่ `sound01.mp3` (ใช้ชื่อเดิม)
ถ้าอยากใช้ชื่ออื่น แก้บรรทัด `const MUSIC_SRC = 'sound01.mp3';` ในสคริปต์
กับ `src` ของแท็ก `<audio id="bgm">`

**เปลี่ยนเพลงเฉพาะคาบนั้น** — กดปุ่ม **📁 เลือกเพลง** แล้วเลือกไฟล์จากเครื่อง
เปลี่ยนได้ทันทีโดยเกมไม่รีเซ็ต แต่ไม่ถูกจำไว้หลังรีเฟรชหน้า
(เปิดจาก `file://` เบราว์เซอร์บล็อกการเก็บข้อมูลถาวร)

ถ้าหาไฟล์เพลงไม่เจอหรือเบราว์เซอร์โหลดไม่ได้ เกมจะขึ้นแถบเตือนบอกให้ทราบ
และยังเล่นได้ตามปกติ แค่ไม่มีเสียงประกอบ

> เพลงที่ใส่เป็นไฟล์ของผู้ใช้เอง ถ้าจะแจกจ่ายไฟล์เกมนี้ต่อหรืออัปขึ้นเว็บสาธารณะ
> ควรตรวจว่ามีสิทธิ์ใช้และเผยแพร่เพลงนั้นด้วย

## เสียงอ่านภาษาไทย (TTS)

ใช้ `speechSynthesis` ของเบราว์เซอร์ ซึ่ง**ต้องมีเสียงภาษาไทยติดตั้งในเครื่อง**

- ✅ Android / iOS / macOS — มักมีอยู่แล้ว
- ⚠️ Windows — ถ้าไม่มี ให้ไป *Settings → Time & language → Language & region →*
  เพิ่มภาษา **ไทย** แล้วติดตั้งส่วนเสริม **Speech**
- ถ้าไม่มีเสียงไทย เกมยังเล่นได้ปกติ เหลือแค่เพลงประกอบ (จะขึ้นแถบเตือนเมื่อกดเปิด 🔊)

เมื่อเปิดเสียงเฉลย ระบบจะ **จำกัดจังหวะช้าสุดไว้ที่ 800 มิลลิวินาที** เพื่อให้อ่านชื่อจบคำ
ถ้าต้องการความเร็วระดับ 4–5 เต็มที่ ให้ปิดปุ่ม 🔊

## แก้ไข / เพิ่มประเทศเอง

เปิด `index.html` แล้วหาส่วน `const POOL = [` (ส่วนที่ 2 ของสคริปต์) แต่ละรายการหน้าตาแบบนี้:

```js
{th:'ฝรั่งเศส', f:()=>vS(['#002395','#FFFFFF','#ED2939'])},
```

- `th` — ชื่อที่แสดงตอนกดเฉลย และใช้อ่านออกเสียง
- `f` — ฟังก์ชันคืนค่า SVG ภายในกรอบ `90 x 60`

เพิ่มกี่ประเทศก็ได้ — จำนวนการ์ดต่อชุดยังคุมด้วย `ROW_SIZES` เหมือนเดิม
(ถ้าประเทศในบ่อน้อยกว่าจำนวนใบในแถวใดแถวหนึ่ง แถวนั้นจะได้การ์ดไม่ครบ)

เครื่องมือวาดธงที่มีให้ใช้:

| ฟังก์ชัน | ใช้ทำอะไร |
|---|---|
| `hS([สี...], [น้ำหนัก])` | แถบแนวนอน |
| `vS([สี...], [น้ำหนัก])` | แถบแนวตั้ง |
| `BG(สี)` / `R(x,y,w,h,สี)` / `C(cx,cy,r,สี)` / `P('x,y ...',สี)` | พื้น / สี่เหลี่ยม / วงกลม / รูปหลายเหลี่ยม |
| `STAR(cx,cy,r,สี,แฉก)` | ดาว |
| `unionJack()` | ธงยูเนียนแจ็ก (ใช้ในธงอังกฤษ และย่อลงมุมของธงออสเตรเลีย) |
| `L('M... ', สี, ความหนา)` | เส้น/เส้นทแยง |

### ตรวจสอบข้อมูลหลังแก้

เปิดเกม กด `F12` → แท็บ Console → พิมพ์

```js
__selfCheck()
```

จะตรวจ: จำนวนประเทศ, ชื่อซ้ำ, ธงเรนเดอร์ได้ทุกผืน,
และสุ่มไพ่ 300 รอบเพื่อยืนยันว่าได้ 8 ใบเสมอและไม่ซ้ำภายในแถวเดียวกัน

## เอาขึ้นเว็บ

เป็นไฟล์ HTML ไฟล์เดียว จึงอัปโหลดที่ไหนก็ได้:

- **Google Apps Script** — สร้างโปรเจกต์ใหม่ → ไฟล์ HTML ชื่อ `Index` → วางเนื้อหาทั้งหมด →
  `Code.gs` ใส่ `function doGet(){ return HtmlService.createHtmlOutputFromFile('Index'); }` → Deploy เป็น Web app
- **Vercel / Netlify / GitHub Pages** — วางไฟล์ในโฟลเดอร์เปล่าแล้ว deploy ได้เลย
- **แชร์ไฟล์ตรงๆ** — ส่งไฟล์ให้ครูท่านอื่นเปิดจากเครื่องได้ทันที

## ฟอนต์

ใช้ **Prompt** ของ Google Fonts (สัญญาอนุญาต SIL OFL 1.1 — ฝังลงไฟล์ได้)
โดยฝังเป็น base64 ในไฟล์ ทั้งชุดภาษาไทยและละติน น้ำหนัก 400 / 600 / 800
จึงยัง**ไม่ต้องต่ออินเทอร์เน็ต**และไม่เรียกไฟล์จากอินเทอร์เน็ตเลย (ไฟล์ HTML ~155 KB)
ไฟล์เดียวที่อยู่นอก `index.html` คือเพลง `sound01.mp3`

ถ้าจะเปลี่ยนฟอนต์เอง แก้ `font-family` ในกฎ `body{...}` ที่ต้นแท็ก `<style>`
และถ้าไม่ใช้ Prompt แล้ว ลบบล็อก `@font-face` ทั้ง 6 อันด้านบนออกได้เพื่อลดขนาดไฟล์

## หมายเหตุ

ธงทั้ง 7 ผืนเป็น **ภาพประกอบแบบย่อ** ที่วาดขึ้นใหม่ด้วย SVG (สัดส่วน 3:2 เท่ากันหมด)
ไม่ได้ใช้ไฟล์ภาพภายนอก ธงที่มีรายละเอียดมาก เช่น ยูเนียนแจ็กของอังกฤษ-ออสเตรเลีย และดาว 50 ดวง
ของสหรัฐอเมริกา วาดตามโครงจริงแต่ลดทอนความละเอียดลงให้เห็นชัดบนจอโปรเจกเตอร์
